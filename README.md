# 🛒 LetShop — E-Commerce Frontend

LetShop is a responsive e-commerce frontend website built using **HTML, CSS, and JavaScript**.

The project focuses on creating a simple, responsive, and interactive shopping experience with product browsing, search, cart functionality, and a unique product insight feature called **ShopPulse**.

## ✨ Features

- 🏠 Responsive home page
- 🔍 Product search
- 📦 Product cards
- 🛍️ Add to Cart functionality
- 🛒 Dynamic cart count
- ❤️ Wishlist interaction
- 📂 Product categories
- 📱 Responsive design
- 💻 Desktop, tablet, and mobile layouts
- ⚡ Interactive JavaScript functionality

## 💡 Unique Feature — ShopPulse

### 〽 ShopPulse

ShopPulse is a small product-insight feature designed to provide users with additional information about a product instead of relying only on its normal rating.

Each product can have a **ShopPulse indicator**.

When the user clicks the ShopPulse button, a small popup appears with:

- Product rating
- Selected customer reviews
- Feedback summary
- A simple recommendation

The purpose is to help users identify potential concerns with a product before purchasing.

> **Note:** ShopPulse is currently implemented as a frontend prototype using sample data. It can later be connected to real reviews, backend data, or an AI-based analysis system.

## 📱 Responsive Design

The website is designed for different screen sizes:

```text
Desktop  → 3 Product Columns
Tablet   → 2 Product Columns
Mobile   → 1 Product Column
```

CSS media queries are used to adjust the layout according to the screen size.
